## Configuration finding

The authors' launcher agrees with Appendix A, Table 4 on the disclosed core
settings. It also fixes warmup, weight decay, PPO clipping, an advantage clamp,
seed, steps, epochs, and parallel topology that Table 4 does not disclose.
These are retained as `official_code_only` rather than relabeled as
paper-reported settings.

Two implementation qualifications should remain explicit in later runs:

1. The public code compares NFC-normalized decoded fragments; the paper defines
   synchronization using exact decoded-prefix equality without documenting an
   NFC transform.
2. The public code suppresses failed or large chunks using an infinity sentinel
   and applies a per-token advantage clamp of 10; these safeguards are not part
   of the paper equations.

Accordingly, later efficacy experiments should use distinct run labels for
`upstream-code` and any stricter `paper-equation` implementation.
